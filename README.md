# Полевой атлас

Интерактивная книга по географии для 5–6 классов. [Открыть книгу](https://votruh.github.io/geografia5-6/).

В оглавлении доступны § 5 «Географические открытия XVII–XX вв.» и § 12 «Ориентирование на местности».

## Добавление главы

Поместите HTML, рисунки и озвучку новой главы в папку `chNN/`. Добавьте её карточку в `chapter-list` в `index.html` и используйте относительные ссылки. GitHub Pages публикует файлы из корня ветки `main`.
